# Abhaya GK (AbhayaGK) — Free Odisha GK App | Lucent GK · Odia Grammar · Dictionary

**Abhaya GK** (also known as **AbhayaGK** or **GK by Abhaya**) is a free General Knowledge web app and Android APK for Odisha competitive exam aspirants. Study Lucent GK, Odia Grammar, Odisha GK mock tests and a trilingual English-Odia-Hindi dictionary — all offline, with no login and no forced ads.

## What is Abhaya GK?

Abhaya GK is a free, lightweight study platform built for students preparing for Odisha government exams. It brings together Lucent GK content, Odia Grammar lessons, chapter-wise MCQ practice and a picture dictionary in one place.

**Useful for:**

- Odisha Police SI / Constable
- OPSC / OAS
- Railway Group D / NTPC
- SSC and other Odisha state exams
- School and college GK preparation

## Key Features

### 1. Lucent GK (English + Odia)

Full coverage of major chapters from Lucent’s General Knowledge book, available in both English and Odia:

| Subject              | English | Odia (ଓଡ଼ିଆ) |
|----------------------|---------|--------------|
| Biology              | ✅      | ✅           |
| Chemistry            | ✅      | ✅           |
| Economics            | ✅      | ✅           |
| History              | ✅      | ✅           |
| Geography            | ✅      | ✅           |
| Physics              | ✅      | ✅           |
| Polity               | ✅      | ✅           |
| Static GK            | ✅      | ✅           |
| Computer Knowledge   | ✅      | —            |
| English Grammar      | ✅      | —            |

### 2. Interactive MCQ Mock Tests

- Chapter-wise sets in English and Odia
- Instant correct / wrong feedback
- Skip button and live score tracking
- Dedicated Odisha GK mock test section

### 3. Odia Grammar (ଓଡ଼ିଆ ବ୍ୟାକରଣ) — 13 Chapters

Complete coverage including ଭାଷା, ଶବ୍ଦ ଗଠନ, ବାକ୍ୟ, ସନ୍ଧି, ପ୍ରତ୍ୟୟ, ରୁଢ଼ି ଓ ଲୋକବାଣୀ, ସମାସ, କାରକ ଓ ବିଭକ୍ତି, ଣତ୍ବ ବିଧି ଷତ୍ବ ବିଧି, ଛନ୍ଦ, ଅଳଙ୍କାର, ବିଶେଷ୍ୟ ବିଶେଷଣ and ଅବ୍ୟୟ.

### 4. Interactive Mind Maps

Collapsible, colour-coded topic trees with expand/collapse controls and notes under each node — ideal for quick revision on mobile.

### 5. Full-Screen Reader + Text-to-Speech

- Comfortable reading layout
- Sentence highlighting while reading
- Multilingual TTS (Odia, Hindi, English) with automatic language detection
- Resume from the last sentence you tapped
- Native Android TTS support when installed as APK

### 6. Trilingual Dictionary (English · Odia · Hindi)

- Offline-capable search
- Image support and auto-suggestions
- Speak results in all three languages
- Tap any word in reader mode to look it up instantly

### 7. Open Your Own Files

Import `.txt`, `.pdf` or `.html` study material. HTML files with nested lists are automatically shown as mind maps.

### 8. Offline-First

All content, fonts and the dictionary database are cached with IndexedDB after the first load. Subsequent visits work without internet.

## How to Use

1. Open [https://abhayattcc.github.io/abhaya-gk/](https://abhayattcc.github.io/abhaya-gk/) in any modern browser.
2. Choose a section (Odisha GK, Lucent GK, Odia Grammar, etc.).
3. Study theory, practise MCQs or explore mind maps.
4. Tap words to open the dictionary; use the Speak button for text-to-speech.
5. Optionally install as an Android APK for native TTS and offline use.

## Tech Stack

| Technology              | Purpose                              |
|-------------------------|--------------------------------------|
| Vanilla HTML / CSS / JS | Core app (no heavy frameworks)       |
| SQL.js + WebAssembly    | In-browser SQLite dictionary         |
| IndexedDB               | Offline caching                      |
| pako.js                 | Gzip decompression                   |
| PDF.js                  | In-app PDF reading                   |
| Web Speech API          | Browser TTS                          |
| Android TTS Bridge      | Native voice quality in APK          |
| Noto Sans               | Odia, Hindi and English scripts      |
| PWA Manifest            | Installable on Android / iOS         |

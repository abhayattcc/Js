    • ପୂର୍ବ ପ୍ରତ୍ୟୟ ବା ଉପସର୍ଗ

      ଧାତୁର ପୂର୍ବ ବ୍ୟବହୃତ ଅବ୍ୟୟ
      ସଂସ୍କୃତ ଭାଷାରେ ସମୁଦାୟ ୨୦ଟି ଉପସର୍ଗ ପ୍ରଚଳିତ,
       ଯଥା - ପ୍ର, ପରା, ଅପ, ସମ୍, ନି, ଅଧୁ, ସୁ, ନିର, ଦୁର, 
      ଉତ୍, ଅତି, ପରି, ପ୍ରତି, ଅବ , ଅନୁ, ବି, ଅଭି, ଉପ, ଅପି ଏବଂ ଆ ।

      • ପ୍ରଦାନ ପ୍ର – ଦା – ଅନ ଦେବା

      • ପରାଜୟ ପରା - ଜି– ଅ ହାର

      • ଅପମାନ ଅପ - ମାନ୍ – ଅ ମାନହାନି

      • ସଂସାର ସମ୍ - ସୃ -ଅ ଜଗତ

      • ନିପୁଣ ନି - ପୁଣ -ଅ କୁଶଳ

      • ଅଧିବାସୀ ଅଧି – ବସ୍ - ଇନ୍ ବାସିନ୍ଦା

      • ସୁନାମ ସୁ - ନାମ ପ୍ରଶଂସା

      • ନିର୍ଜଳ ନିର୍ - ଜଳ – ଅ ଜଳଶୂନ୍ୟ

      • ଦୁର୍ଭାଗ୍ୟ ଦୁର- ଭାଗ୍ୟ ମନ୍ଦ ଭାଗ୍ୟ

      • ଉତ୍କର୍ଷ ଉତ୍-କୃଷ୍-ଅ ଶ୍ରେଷ୍ଠତା

      • ଅତ୍ୟଧିକ ଅତି - ଅଧିକ ଖୁବବେଶି

      • ପରିଶ୍ରମ ପରି – ଶ୍ରମ୍ - ଅ ବିଶେଷ ଶ୍ରମ

      • ପ୍ରତିକୂଳ ପ୍ରତି – କୂଳ ବିରୁଦ୍ଧ

      • ଅବସ୍ଥାନ ଅବ- ସ୍ଥା – ଅନ ବାସସ୍ଥାନ

      • ଅନୁକରଣ ଅନୁ – କୃ – ଅନ ନକଲିକରଣ

      • ବିଖ୍ୟାତ ବି - ଖ୍ୟା-ତ ପ୍ରସିଦ୍ଧ

      • ଅଭିଜ୍ଞାନ ଅଭି-ଜ୍ଞା- ଅନ

      • ଉପକରଣ ଉପ- କୃ – ଅନ ସରଞ୍ଜାମ

      • ଅପିଧାନ ଅପି - ଧା - ଅନ ଆଚ୍ଛାଦନ

      • ଆକର୍ଷଣ ଆ- କୃଷ୍- ଅନ ଟାଣିବା

      • ବହିଃ’ : ବହିର୍ଜଗତ, ବହିଷ୍କାର, ବହିର୍ଭୁତ

      • ଆବିଃ’ : ଆବିର୍ଭାବ, ଆବିଷ୍କାର, ଆବିଷ୍କୃତ

      • ସତ୍’ : ସତ୍‌ସଙ୍ଗ, ସଦୁପଯୋଗ, ସଦୁପାୟ

  • କୃଦନ୍ତ

    କୃତ୍ (ସଂସ୍କୃତ) + ଅନ୍ତ୍ (ଶେଷରେ)
    ଧାତୁ ପରେ ସଂସ୍କୃତ ପ୍ରତ୍ୟୟ ଲାଗେ
    (ଧାତୁ+ ପ୍ରତ୍ୟୟ) 
    ସଂସ୍କୃତ କୃତ୍ ପ୍ରତ୍ୟୟ = ଅ, ଅନ, ଅକ, ତବ୍ୟ, 
    ଅନୀୟ, ଇତ୍ର, ତ୍ର, ତୃ, ତି, ଇନ୍, ତ,
     ଯ, ଇଷ୍ଣୁ,ଉକ, ଉର, ର, ଉ 

    • ଜି + ଅ = ଜୟ

    • ସ୍ମୃ + ଅନ =ସ୍ମରଣ

    • କୃ + ଅକ = କାରକ

    • ଭୂ + ଉକ =ଭାବୁକ

    • ଜଳ - ଧା + ଇ = ଜଳଧି

    • ସହ୍ + ଇଷ୍ଣୁ =ସହିଷ୍ଣୁ

    • ସ୍ଥା + ଇନ୍ = ସ୍ଥାୟୀ

    • ଶୁଧ୍ + ତ =ଶୁଦ୍ଧ

    • ପଚ୍ + ତ =ପକ୍ୱ

    • ଭଜ୍ + ତି =ଭକ୍ତି

    • ଶମ୍ + ତି =ଶାନ୍ତି

    • କୃ + ତବ୍ୟ = କର୍ତ୍ତବ୍ୟ

    • ପଠ୍ + ଅନୀୟ = ପଠନୀୟ

    • ଚର୍ + ଇତ୍ର = ଚରିତ୍ର

    • ପଠ+ ଯ = ପାଠ୍ୟ

    • କୃ + ଯ = କାର୍ଯ୍ୟ

    • ଶାସ୍ + ଯ =ଶିଷ୍ୟ

    • ନୀ + ତ୍ର = ନେତ୍ର

    • କ୍ଷି + ତ୍ର =କ୍ଷେତ୍ର

    • ପା +ତୃ = ପିତୃ/ପିତା

    • କ୍ଷୁଦ୍ +ର = କ୍ଷୁଦ୍ର

    • ପ୍ରଚ୍ଛ୍ + ନ = ପ୍ରଶ୍ନ

    • ବିଦ୍ + ଉର = ବିଦୁର

    • ସନନ୍ତ ପଦ

      ସନ୍ ପ୍ରତ୍ୟୟ ଦ୍ୱାରା ନିଷ୍ପନ୍ନ
      ପଦକୁ ‘ସନ୍ନନ୍ତ ପଦ’ କୁହାଯାଏ । 
      ସନ୍’ ପ୍ରତ୍ୟୟ ପରେ ‘ଆ’ ବା ‘ଉ’ ପ୍ରତ୍ୟୟ ଯୋଗ

      • ସନ୍ ପ୍ରତ୍ୟୟ

        ପିଇବାର ଇଚ୍ଛା = ପିପାସା (ପା – ସନ୍ + ଆ)
        ଜାଣିବାର ଇଚ୍ଛା = ଜିଜ୍ଞାସା (ଜ୍ଞା – ସନ୍ + ଆ)
        ଜୟ କରିବାର ଇଚ୍ଛା = ଜିଗୀଷା (ଜି - ସନ୍ + ଆ)
        ହତ୍ୟା କରିବାର ଇଚ୍ଛା = ଜିଘାଂସା (ହନ୍- ସନ୍ + ଆ)
        ଲାଭ କରିବାର ଇଚ୍ଛା = ଲିପ୍ସା (ଲଭ୍ – ସନ୍ + ଆ)
        ଦେଖିବାର ଇଚ୍ଛା = ଦିଦୃକ୍ଷା (ଦୃଶ୍ – ସନ୍ + ଆ)
        କରିବାର ଇଚ୍ଛା = ଚିକୀର୍ଷା (କୃ– ସନ୍ + ଆ)
        ଦାନ କରିବାର ଇଚ୍ଛା = ଦିତ୍ସା (ଦା – ସନ୍ + ଆ)
        ଶୁଣିବାର ଇଚ୍ଛା = ଶୁଶ୍ରୂଷା (ଶ୍ରୁ - ସନ୍ + ଆ)
        ମୁକ୍ତି ପାଇବାର ଇଚ୍ଛା = ମୁମୁକ୍ଷା (ମୁଚ୍ – ସନ୍ + ଆ)
        ମରିବାର ଇଚ୍ଛା = ମୁମୂର୍ଷା (ମୃ – ସନ୍ + ଆ)
        ପିଇବାକୁ ଇଚ୍ଛୁକ = ପିପାସୁ (ପା – ସନ୍ + ଉ)
        ଖାଇବାକୁ ଇଛୁକ= ବୁବୁକ୍ଷୁ (ଭୂଜ୍ - ସନ୍ + ଉ)
        ଜାଣିବାକୁ ଇଚ୍ଛୁକ = ଜିଜ୍ଞାସୁ (ଜ୍ଞା – ସନ୍ + ଉ)
        ଲାଭକରିବାକୁ ଇଚ୍ଛୁକ = ଲିପ୍ସୁ (ଲଭ୍ – ସନ୍ + ଉ)

        • ତଦ୍ଧିତ

          ତତ୍ + ହିତ 
          ତାହାର (ମୂଳ ଶବ୍ଦର) + ମଙ୍ଗଳ (ବ୍ୟବହାର ରେ ଅର୍ଥ ପରିବର୍ତ୍ତନ)
          (ଶବ୍ଦ+ ପ୍ରତ୍ୟୟ) 
          ନୀତି + ଇକ = ନୈତିକ ( ନୀତି ର ବ୍ୟବହାର କୁ ବୁଝାଏ)

          • ବିଷ୍ଣୁ + ଅ = ବୈଷ୍ଣବ

          • ସୂର୍ଯ୍ୟ + ଅ = ସୌର

          • ଶିଶୁ + ଅ = ଶୈଶବ

          • କୁଶଳ + ଅ = କୌଶଳ

          • ବିଶାଖା +ଅ = ବୈଶାଖ

          • ଦେବ + ଅ = ଦୈବ

          • ଭରତ + ଅ =ଭାରତ

          • ବିଦେହ + ଅ=ବୈଦେହ

          • ବ୍ୟାକରଣ + ଅ = ବୈୟାକରଣ

          • ବଶିଷ୍ଠ + ଅ = ବାଶିଷ୍ଠ

          • ବିଦ୍ୟା + ଅ = ବୈଦ୍ୟ

          • ସାହିତ୍ୟ + ଇକ = ସାହିତ୍ୟିକ

          • ତିଳ + ଇକ =ତୈଳିକ

          • ଅକସ୍ମାତ୍ + ଇକ = ଆକସ୍ମିକ

          • ଦଶରଥ + ଇ = ଦାଶରଥି

          • ବଂଶ + ଈୟ = ବଂଶୀୟ

          • ଜାତି + ଈୟ = ଜାତୀୟ

          • କୁଳ + ଈନ = କୁଳୀନ

          • ନବ + ଈନ = ନବୀନ

          • ସର୍ବଜନ + ଈନ =ସାର୍ବଜନୀନ/ସର୍ବଜନୀନ

          • ଗଙ୍ଗା + ଏୟ = ଗାଙ୍ଗେୟ

          • ଅତିଥି + ଏୟ = ଆତିଥେୟ

          • ଫଳ + ଇତ = ଫଳିତ

          • ଜଟା + ଇଳ = ଜଟିଳ

          • ମେଧା + ବିନ = ମେଧାବୀ

          • ମୂଲ୍ୟ + ବତ୍ = ମୂଲ୍ୟବାନ୍

          • ଅଦିତି + ଯ = ଆଦିତ୍ୟ

          • ତାଳୁ + ଯ = ତାଲବ୍ୟ

          • ଗ୍ରାମ + ଯ = ଗ୍ରାମ୍ୟ

          • ବଣିଜ + ଯ = ବାଣିଜ୍ୟ

          • ସୁନ୍ଦର + ଯ =ସୌନ୍ଦର୍ଯ୍ୟ

          • ଗୁରୁ + ତୁ = ଗୁରୁତ୍ୱ

          • ଏକ + ଦା = ଏକଦା

          • ସର୍ବ + ଦା = ସର୍ବଦା

          • ବୃହତ୍ + ତମ = ବୃହତ୍ତମ

          • ବୃଦ୍ଧ + ଇଷ୍ଟ = ଜ୍ୟେଷ୍ଠ

          • ଶ୍ରଦ୍ଧା + ଆଳୁ = ଶ୍ରଦ୍ଧାଳୁ

  • ସମାସ

    • (ଏକାପଦୀକରଣ)

      ପରସ୍ପର ସମ୍ବନ୍ଧ ଥିବା 2 ବା ତତୋଧିକ ଶବ୍ଦ ମାନଙ୍କ ସମାହାର

      Ex - ସିଂହ ଚିହ୍ନିତ ଆସନ= ସିଂହାସନ
      ସିଂହ - ପୂର୍ବ ପଦ 
      ଆସନ - ପରପଦ 
      ସିଂହାସନ - ସମସ୍ତ ପଦ
      ସମସ୍ୟା ମାନ ପଦ = ସିଂହ, ଆସନ
      ବିଗ୍ରହ ବାକ୍ୟ ବା ସମାସ ବାକ୍ୟ = ସମାସ ରେ ବ୍ୟବହୃତ ବାକ୍ୟ
      Ex- ରାମ ସିଂହ ଚିହ୍ନିତ ଆସନରେ ବସିଛନ୍ତି |

      • ପୂର୍ବ ପଦ ପ୍ରଧାନ

        • ଦ୍ଵିଗୁ ସମାସ

          ସଂଖ୍ୟା ବାଚକ ଶବ୍ଦ ପୂର୍ବରେ ଥାଇ ଗଠିତ

          ଦ୍ଵିଗୁ ମାନେ ଦୁଇ 
          ଦୁଇ ମାନେ ସଂଖ୍ୟା

          • ଚାରି ବେଦର ସମାହାର = ଚାରିବେଦ

          • ପାଞ୍ଚ ଇନ୍ଦ୍ରିୟର ସମାହାର = ପଞ୍ଚେନ୍ଦ୍ରିୟ

          • ସାତ ଦିନର ସମାହାର= ସପ୍ତାହ

        • ଅବ୍ୟୟୀ ସମାସ

          ଅବ୍ୟୟ ପଦ ସମାସର ପୂର୍ବ ପଦରେ ଥାଏ
          ଭିକ୍ଷା ର ଅଭାବ = ଦୁର୍ଭିକ୍ଷ {( ଦୂର୍= ଅବ୍ୟୟ)+ଭିକ୍ଷ}

          • ରୂପ ର ଯୋଗ୍ୟ = ଅନୁ ରୂପ ( ଅନୁ= ଅବ୍ୟୟ)

          • ଶକ୍ତି କୁ ଅତିକ୍ରମ ନ କରି = ଯଥା ଶକ୍ତି (ଯଥା = ଅବ୍ୟୟ)

          • ପଶ୍ଚାତ୍ ସନ୍ଧାନ = ଅନୁ ସନ୍ଧାନ ( ଅନୁ = ଅବ୍ୟୟ)

            ସେହି ପରି ହେବ ଅନୁକରଣ, ଅନୁତାପ, ଅନୁଗମନ

          • ମୃତ୍ତି ର ସଦୃଶ = ପ୍ରତି ମୃତ୍ତି ( ପ୍ରତି = ଅବ୍ୟୟ)

            ସେହି ପରି ଉପବନ ଓ ଉପ ଭାଷା ହେବ

          • କୁଳ ର ବିପରୀତ = ପ୍ରତିକୂଳ ( ପ୍ରତି = ଅବ୍ୟୟ)

      • ଉତ୍ତର ପଦ ପ୍ରଧାନ

        • ତତ୍ ପୁରୁଷ ସମାସ

          ଦ୍ଵିତୀୟା ବିଭକ୍ତି ଠାରୁ ସପ୍ତମୀ ବିଭକ୍ତି ପର୍ଯ୍ୟନ୍ତ
          ବିଶେଷ୍ୟ ପଦ ସହ ବିଶେଷ୍ୟ କିମ୍ବା ବିଶେଷଣ 
          ପଦ ର ସମାହାର ରେ ଗଠିତ

          • ଦ୍ଵିତୀୟା

            • ଗୃହ କୁ ଆଗତ = ଗୃହାଗତ ( କୁ =ବିଭକ୍ତି)

            • ଧନକୁ ପ୍ରାପ୍ତ = ଧନ ପ୍ରାପ୍ତ( କୁ =ବିଭକ୍ତି)

          • ତୃତୀୟା

            • ସର ଦ୍ଵାରା ଆହତ = ସରାହାତ (ଦ୍ଵାରା =ବିଭକ୍ତି)

            • ବିଦ୍ୟାରେ ହିନ = ବିଦ୍ୟା ହୀନ {ରେ =ବିଭକ୍ତି)

          • ଚତୁର୍ଥୀ

            • ପୁତ୍ର ନିମିତ୍ତ ଶୋକ = ପୁତ୍ରଶୋକ { ନିମିତ୍ତ =ବିଭକ୍ତି}

            • ଦେବଙ୍କୁ ଅର୍ପିତ = ଦେବାର୍ପିତ {ଙ୍କୁ =ବିଭକ୍ତି}

          • ପଞ୍ଚମୀ

            • ବିଦେଶରୁ ଆଗତ= ବିଦେଶା ଗତ { ରୁ =ବିଭକ୍ତି}

            • ଗୋଠରୁ ଖଣ୍ଡିଆ ଗୋଠ ଖଣ୍ଡିଆ { ରୁ =ବିଭକ୍ତି}

            • ରୋଗରୁ ମୁକ୍ତ = ରୋଗ ମୁକ୍ତ { ରୁ =ବିଭକ୍ତି}

          • ଷଷ୍ଠୀ

            • ଗାଁ ର ମୁଣ୍ଡ = ଗାଁମୁଣ୍ଡ {ର =ବିଭକ୍ତି}

            • ଚନ୍ଦ୍ର ର ଅର୍ଦ୍ଧ = ଅର୍ଦ୍ଧଚନ୍ଦ୍ର {ର =ବିଭକ୍ତି}

            • କର୍ମ ର ଫଳ = କର୍ମ ଫଳ {ର =ବିଭକ୍ତି}

            • ମାତୃ ର ଭାଷା = ମାତୃ ଭାଷା {ର =ବିଭକ୍ତି}

            • ଅହନ୍ ର ମଧ୍ୟ = ମଧ୍ୟାହ୍ନ {ର =ବିଭକ୍ତି}

            • ଅହନ୍ ର ପୂର୍ବ = ପୂର୍ବାହ୍ଣ {ର =ବିଭକ୍ତି}

            • ହଂସ ମାନଙ୍କ ରାଜା = ହଂସ ରାଜା {ମାନଙ୍କର =ବିଭକ୍ତି}

            • ରାଜା ମାନଙ୍କର ନୀତି= ରାଜନୀତି {ମାନଙ୍କର=ବିଭକ୍ତି}

          • ସପ୍ତମୀ

            • ସାହିତ୍ୟ ରେ ନିପୁଣ = ସାହିତ୍ୟ ନିପୁଣ { ରେ = ବିଭକ୍ତି}

            • ବିଦ୍ୟାରେ ନିପୁଣ = ବିଦ୍ୟା ନିପୁଣ { ରେ = ବିଭକ୍ତି}

            • ବଣ ରେ ଭୋଜି = ବଣଭୋଜି { ରେ = ବିଭକ୍ତି}

          • ନ ଞ 

            ପୂର୍ବ ପଦରେ ନ ବ୍ୟବହାର

            • ନ ଓସାରିଆ = ଅଣ ଓସାରିଆ

            • ନ ଉଚିତ୍ = ଅନୁଚିତ୍

          • ଉପପଦ ତତ୍ ପୁରୁଷ

            ଧାତୁ (ଶବ୍ଦ ର ମୂଳ ରୂପ) ପୂର୍ବରୁ ଆଉଗୋଟିଏ ପଦ

            • କୁଳ ବୁଡାଏ ଯେ = କୁଳ ବୁଡ଼ା

            • ମଧୁ ପାନ କରେ ଯେ = ମଧୂପ (ମଧୁ = ଉପ ପଦ)

          • ଆଲୁକ୍ ସମାସ

            ବିଭକ୍ତି ଲୁପ୍ତ ହୁଏ ନାହିଁ

            • ଯୁଧି (ସପ୍ତମୀ ବିଭକ୍ତି) ସ୍ଥିର = ଯୁଧିଷ୍ଠିର

            • ବନେ (ସପ୍ତମୀ ବିଭକ୍ତି) ଚରେ ଯେ= ବନେଚର

        • କର୍ମଧାରୟ ସମାସ

          ବିଶେଷ୍ୟ ଓ ବିଶେଷଣ ପଦକୁ ନେଇ ଗଠିତ

          • ନୀଳ (ବିଶେଷଣ) ଅଟେ କଇଁ (ବିଶେଷ୍ୟ)= ନୀଳ କଇଁ

          • ଯେ ରୁଦ୍ର (ବିଶେଷ୍ୟ) ସେ ସୁନ୍ଦର (ବିଶେଷଣ)= ରୁଦ୍ର ସୁନ୍ଦର

          • ଯେ ରାଜ(ବିଶେଷ୍ୟ) ସେ ଋଷି (ବିଶେଷ୍ୟ)= ରାଜର୍ଷି

          • ଶ୍ରେଷ୍ଠ (ବିଶେଷଣ) ଅଟେ ନର(ବିଶେଷ୍ୟ) = ନର ଶ୍ରେଷ୍ଠ

          • ରୂପକ କର୍ମ ଧାରୟ


            ଉପମାନ ଓ ଉପମେୟ କୁ ନେଇ ଅର୍ଥ ପରିବର୍ତ୍ତନ ନକରି ସମାସ ଗଠନ
            ଯେମିତି ଦେଖାଯାଏ ସେମିତି ହିଁ ଗଠନ
            ଉପମାନ =ଯାହା ବିଷୟରେ ତୁଳନା କରାଯାଏ (ପ୍ରକୃତ ବସ୍ତୁ)
            ଉପମେୟ = ପ୍ରକୃତ ବସ୍ତୁ ସହ ଯାହାର ତୁଳନା କରାଯାଏ
            ଶୋକ(ଉପମେୟ) ରୂପକ ସାଗର(ଉପମାନ)= ଶୋକ ସାଗର

            • କନ୍ୟା ରୂପକ ରତ୍ନ = କନ୍ୟା ରତ୍ନ

            • ଉପମାନ କର୍ମ ଧାରୟ

              କେବଳ ଉପମାନ କୁ ନେଇ ଗଠିତ

              • ଘନ (ଉପମାନ/ପ୍ରକୃତ ବସ୍ତୁ) ପରି ଶ୍ୟାମ (ସାଧାରଣ ଧର୍ମ)= ଘନ ଶ୍ୟାମ

            • ଉପମିତ କର୍ମ ଧାରୟ

              ଉପମେୟ ପୂର୍ବ ପଦରେ ଓ ଉପମାନ ପର ପଦରେ ଥାଏ

              • ମୁଖଟି (ଉପମେୟ) ଚନ୍ଦ୍ର (ଉପମାନ) ପରି= ଚନ୍ଦ୍ର ମୁଖ

              • ନର (ଉପମେୟ) ପରି ସିଂହ(ଉପମାନ) = ନର ସିଂହ

            • ମଦ୍ୟପଦ ଲୋପୀ କର୍ମ ଧାରୟ

              ମଧ୍ୟ ପଦ ଟି ଲୋପ ପାଇ ଥାଏ

              • ସିଂହ (ପୂର୍ବ ପଦ) ଚିହ୍ନିତ (ମଧ୍ୟ ପଦ) ଦ୍ଵାର (ପର ପଦ) = ସିଂହ ଦ୍ୱାର

              • ସୁନା ରେ(ପୂର୍ବ ପଦ) ତିଆରି (ମଧ୍ୟ ପଦ) ମୁଦି (ପର ପଦ) = ସୁନା ମୁଦି

              • ବର (ପୂର୍ବ ପଦ) ନାମକ (ମଧ୍ୟ ପଦ) ଗଛ (ପର ପଦ) = ବର ଗଛ

        • ଦ୍ଵନ୍ଦ ସମାସ

          ପ୍ରତ୍ୟେକ ପଦର ପ୍ରାଧାନ୍ୟ ଥାଇ ଏକାଧିକ ବିଶେଷ୍ୟ ପଦର ସମାହାର

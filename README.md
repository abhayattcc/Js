## 📌 What is AbhayaGK?

**AbhayaGK** is a free, lightweight, and powerful web application (also available as an Android APK) designed for students preparing for **Odisha competitive exams** such as:

- 🏛️ Odisha Police SI / Constable
- 📝 OPSC / OAS (Odisha Administrative Service)
- 🚂 Railway Group D / NTPC
- 🏦 SSC / Bank exams
- 📚 Odisha Government Job exams
- 🎓 School & College GK competitions

The app brings together **Lucent GK content**, **Odia Grammar**, **Odia GK mock tests**, and a **multilingual dictionary** — all in one place, completely free.

### 🧩 2. Interactive MCQ Mock Tests

Practice with **chapter-wise MCQ mock tests** in both English and Odia:

- ✅ Multiple choice questions with **4 options**
- ✅ Instant **correct/wrong feedback** after each answer
- ✅ **Skip button** to move past difficult questions
- ✅ **Live score tracking** — score and attempted count shown in real time
- ✅ **Subject-wise batched sets** — study one topic at a time
- ✅ Supports both **English MCQs** and **Odia MCQs (ଓଡ଼ିଆ ପ୍ରଶ୍ନ)**
- ✅ Dedicated **Odisha GK Mock Test** section

---

### 🗺️ 3. Interactive Mind Maps

Visual learning made easy with **collapsible mind maps**:

- 🌲 Hierarchical topic tree with color-coded levels
- ➕ Expand All / ⊟ Collapse All controls
- 📝 Notes under each node (key facts highlighted)
- 🎨 6 color levels for deep topic nesting
- Works perfectly on mobile screens

### 📖 4. Full-Screen Reader Mode

A dedicated **reader mode** for theory content:

- 📜 Comfortable reading layout with large fonts
- 🔆 Sentence-level highlight as you read
- 💬 Tap any word to instantly look it up in the dictionary
- 🔙 Back/Home navigation buttons
- 📂 Support for opening your own `.txt`, `.pdf`, or `.html` files

---

### 🗣️ 5. Text-to-Speech (TTS) — Read Aloud in Odia, Hindi & English

AbhayaGK has a powerful **multilingual TTS engine**:

- 🎙️ Reads content aloud in the **correct language** (Odia, Hindi, or English) — automatically detected
- ▶️ **Play / Pause / Stop** controls
- 📍 Resumes from the **last sentence you tapped** — never lose your place
- 🤖 **Android TTS bridge** — uses native Android TTS when installed as an APK for better pronunciation
- 🔊 Language-aware: Odia script → Odia voice, Hindi → Hindi voice, English → English voice

### 🔤 7. Trilingual Dictionary — English, Odia & Hindi

A built-in **offline-capable dictionary** with English → Odia → Hindi lookup:

- 🔍 Search any word in English, Odia, or Hindi
- 🖼️ Dictionary entries with **images** (visual learning)
- 🗑️ Delete/restore images per word
- 💡 **Auto-suggestions** as you type
- 🗣️ **Speak the dictionary result** in all three languages
- Tap any word in reader mode to instantly open the dictionary popup
- Powered by a compressed SQLite database (cached locally with IndexedDB)

---

### 📄 8. Open Your Own Files

AbhayaGK isn't limited to built-in content — open your own study files:

- 📝 `.txt` files — plain text notes
- 📑 `.pdf` files — study PDFs with page-by-page navigation
- 🌐 `.html` files — interactive HTML study material (auto-detected as mind map or reader)

---

### ⚡ 9. Offline-First with IndexedDB Caching

No internet? No problem:

- 🗄️ All content files, fonts, and databases are **cached locally** using IndexedDB
- First load fetches everything; subsequent loads work **offline**
- SQL.js + WebAssembly powers the dictionary database in-browser
- Progress bar shown during initial asset download

---

### 📱 10. Android APK — Install as a Native App

AbhayaGK is available as a native **Android APK**:

- Converted from web app to APK
- Uses **Android TTS bridge** for superior voice quality
- Hardware back button support (`window._appGoBack` bridge)
- Responsive design — works on all Android screen sizes

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Vanilla HTML / CSS / JS | Core app (no frameworks) |
| SQL.js + WebAssembly | In-browser SQLite for dictionary |
| IndexedDB | Offline caching of all assets |
| pako.js | Gzip decompression of DB files |
| PDF.js | In-app PDF reader |
| Web Speech API | Browser TTS |
| Android TTS Bridge | Native TTS in APK mode |
| Noto Sans font | Odia, Hindi, English script support |
| PWA Manifest | Installable on Android/iOS |
